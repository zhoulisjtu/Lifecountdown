光阴 · 时光格子

一个人只拥有此生此世是不够的，他还应把日子一格一格亲手点亮。

关于

光阴把你的生命画成 900 个格子——每个格子是一轮满月升起。设定生日那一刻，已走过的格子被点亮；橙色的呼吸格，是正在升起的这一轮。

功能

生命格子以月为单位点亮已度过的人生，一眼看清来路与余量。
月度仪式每月一次，30 秒，点亮一格，为这个月留一句话。
心愿与瞬间记录你想实现的事，和你认真度过的时刻。
仅存本机所有数据只保存在你自己的 iPhone 上，不联网、不收集任何信息。

常见问题

我的数据存在哪里？

全部在你自己的 iPhone 上。本 App 不联网、不上传任何数据；卸载 App 即删除全部数据。

格子是怎么算的？

用你的出生日期和默认 75 年寿命（可在设置中调整，40–100 年），把已过的人生按月点亮成格子。这只是提醒工具，不是预测。

通知不响？

去 系统设置 → 光阴 → 通知，确认允许通知。该权限仅用于你主动开启的月度提醒。

照片会读取我的相册吗？

不会。只有你在「时刻」或更换头像时主动选中的照片才会被复制进 App 本地目录，App 无法浏览你的其他照片。

App 锁是怎么工作的？

App 锁使用面容 ID / 触控 ID 或设备密码（系统本地认证），不设独立密码，无需记忆额外密码。

如何彻底删除我的数据？

卸载 App，或 App 内逐条删除心愿、时刻、个人资料。数据不离开本机，删除即彻底。
